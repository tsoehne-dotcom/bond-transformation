BOND TRANSFORMATION – GITHUB PAGES

1. GitHub: Neues PUBLIC Repository erstellen, z.B. bond-transformation.
2. Add file > Upload files: Inhalt dieses Ordners hochladen (index.html, sw.js, manifest.webmanifest, alle PNGs). README.txt optional.
3. Settings > Pages > Build and deployment: Deploy from a branch, Branch main, Folder /(root), Save.
4. Nach Bereitstellung: https://DEINNAME.github.io/bond-transformation/ in Safari (iPhone) oder Chrome (Android) öffnen.
5. iPhone: Teilen > Zum Home-Bildschirm. Android: Menü > App installieren.
6. Für Offline-Nutzung einmal vollständig online laden und danach erst testen (Flugmodus).

ACHTUNG: GitHub Pages ist öffentlich erreichbar. Trainingsdaten werden lokal im Browser gespeichert.
Vor Updates Trainingsstand als JSON exportieren. Nach Upload einer neuen Version App schließen und neu öffnen; der Service Worker kann alte Dateien bis zum nächsten Start behalten.
